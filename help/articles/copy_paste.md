COPYING AND PASTING A COMPONENT
Select the component by tapping it or components by using the marquee tool, then tap the Copy command in the toolbar. This copies the components into the clipboard.

Next tap the paste command in the toolbar and tap a blank location on the canvas you want to paste the copied entities. You can paste multiple times as long as the copied entities remain in the clipboard. 
All properties of the original component are copied except for the component name. The name is autogenerated for the copied entities. You can use the properties panel to change the name values.

TIP
- Use the copy/paste commands to quickly build a circuit by creating duplicates of components that share the same properties. First setup the orientation and electrical parameters of the original component and the use the copy-paste operation.
