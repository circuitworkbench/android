Tap the + button on the bottom left of home screen to open the speed dial. Tap 'New Schematic' to launch the schematic editor with an untitled file name. A blank canvas is ready for component placement. Once you make changes to the editor, remember to save the changes using the command from the toolbar. Circuit names can contain letters, numbers, spaces, hyphens, and underscores.

New circuits are saved to whichever storage location is configured in Settings. You can change the storage location at any time — see Storage Settings for details.
